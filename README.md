# Àdìrè Vibes (LHIS End of Year Thanksgiving)

Static site. No build step.

- index.html: the site
- data.json: budget lines, donors, date, flyer paths (edit this to update the site)
- flyers/: the three flyers (replace a file with the same name to change a flyer)

Vercel: Framework Preset "Other", leave build settings empty.
